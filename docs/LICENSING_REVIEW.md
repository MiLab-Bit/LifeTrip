## Required decisions before publishing a license

1. Confirm code copyright holders and any contributor or employer agreements.
2. Inventory vendored code, dependencies, datasets, fonts, images, music and other assets, including their individual terms.
3. Identify any upstream source requiring attribution, source disclosure or license compatibility.
4. Decide whether code and creative assets should have separate permissions and notices.
5. Choose and approve the intended license(s); then add actual license texts and update README badges and notices consistently.
6. Review distribution and deployment obligations, including commercial use and redistribution.

**Do not infer that public GitHub visibility authorizes reuse, modification or redistribution.**
