# LifeTrip 产品设计方案

> 版本：2026-08 · 仓库：MiLab-Bit/LifeTrip  
> 说明：本方案参考 CityWalk 赛道常见企划结构（含 Kora 类「三轴决策、快速出发、行中可调」思路）。若你本地有 `kora_proposal_*.docx` 全文，可对照补全品牌叙事与商业章节。

---

## 一、一句话

**LifeTrip 是「地铁线路感」的潮流 City Walk 规划器：用 30 秒选好一条线，用地图和站牌式界面，带你逛当下的街面，而不是查文献、做文旅题。**

---

## 二、问题与机会

### 2.1 用户真实痛点

| 痛点 | 表现 |
|---|---|
| **出门决策慢** | 小红书/点评/地图来回切，30 分钟在「搜」，还没迈出门 |
| **网红同质化** | 攻略人人相同，走到的是排队拍照，不是自己的城市节奏 |
| **工具不对题** | 导航只会 A→B，不会「今晚想逛什么气质的路」 |
| **行走中不可调** | 累了、下雨了、想喝咖啡了，整条计划作废 |

### 2.2 机会

- CityWalk 已是年轻人日常休闲方式，但**缺少「气质 + 工具 + 地图」一体化**产品。
- 现有产品多偏「文旅讲解」或「纯地图」，**潮流、当下、可改线**的中间态仍空。
- **视觉差异化**：地铁/线路号/站牌 UI，在 beige 风攻略 App 里一眼可辨。

---

## 三、产品定位

| 维度 | LifeTrip | 常见文旅 App | 纯导航 |
|---|---|---|---|
| 核心资产 | **可逛的街面 POI + 步行节奏** | 景点/典故 | 最短路径 |
| 叙事 | 当下逛法、店招、街角 | 历史百科 | 无 |
| 交互隐喻 | **地铁线 / 站点 / 换乘** | 书单/卡片/音频 | 转向箭头 |
| 决策输入 | 主题、体力、时长、片区 | 景点清单 | 终点 |
| 行中能力 | 改线、跳过、下一站（规划） | 固定导览 | 重算路径 |

**不做什么：** 馆藏文献、典籍人物链、红色叙事、需要上图/图书馆 API 的内容体系。

---

## 四、目标用户

### 4.1 核心 persona

**「下班想出门的城里年轻人」**

- 22–35 岁，一线/新一线
- 不需要「学到知识」，需要 **「今晚这条线值得走」**
- 接受 1.5–2.5 小时步行，排斥跟团式打卡

### 4.2 次要 persona

- **访客/周末游客**：想走本地人会逛的支路，不要外滩三件套 repeat
- **一人行**：需要「站牌式」陪伴感，而不是孤独看地图

---

## 五、体验闭环（学习 Kora / 夜航类企划）

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  出发前      │     │  行走中      │     │  结束后      │
│  Brief 选线  │ ──▶ │  地图+站点   │ ──▶ │  线路归档    │
│  30s 决策    │     │  改线/跳过   │     │  分享/二刷   │
└─────────────┘     └─────────────┘     └─────────────┘
```

### 5.1 出发前 · Brief（已实现 v0.2）

用户输入四组信号：

| 信号 | 字段 | 说明 |
|---|---|---|
| **主题** | `vibe` | 夜行霓虹 / 咖啡 / 古着 / 画廊… |
| **片区** | `district_id` | 安福—武康、愚园—江苏路等 bbox |
| **时长** | `duration_min` | 45–150 分钟 |
| **步速** | `pace` | 慢逛 / 标准 / 赶场 |

输出：**一条「线」**（lineCode + 3–5 个「站」），不是散点列表。

### 5.2 行走中 · Walk（部分实现）

- 地图：暗色底图 + **绿色线路** + 站号 marker（已实现）
- 站点卡：headline + 逛法 + TIP（v0.2 规则文案）
- **规划能力（待做）**
  - 跳过当前站
  - 「附近找咖啡」一句话改线
  - 体力耗尽 → 自动缩短剩余站数

### 5.3 结束后 · Archive（待做）

- 本次线路保存（站序、时长、地图截图）
- 「换乘」：同片区换主题再生成
- 可选：轻量分享图（线路 + 3 站名，无社交链也可）

## 六、核心机制：三轴 + 线路感

借鉴 Kora / 夜航类企划，LifeTrip 内部用 **三轴评分** 选站（用户只见「主题 chip」，轴在后台）：

| 轴 | 含义 | 用户可感知字段 |
|---|---|---|
| **Mood 气质** | 夜行 / 安静 / 热闹 / 看展 | `vibe` |
| **Energy 体力** | 步速、站数、单次步行段长度 | `pace` + `duration_min` |
| **Context 场景** | 片区、时段、是否独行 | `district_id` + 未来「时段」 |

**线路感规则（产品宪法）：**

1. 永远输出 **Line**（有 lineCode），不是 POI 清单
2. 每站必须有 **站码**（如 `N1-02`），像地铁换乘
3. 地图上的线 **优先于** 文字列表
4. 所有 POI 必须 **有坐标、有 OSM/curated 来源**，LLM 不得凭空加店

## 七、功能分层路线图

> **原则：一层验证再叠下一层；不先建 monorepo 平台。**

### Layer 0 — 可演示闭环 ✅（当前）

| 模块 | 内容 |
|---|---|
| Web | Brief → Loading → RouteMap → Walk |
| API | Overpass + OSRM + fixture 兜底 |
| 视觉 | 黑绿地铁 token + MapLibre Dark |
| 文案 | 规则模板 |

**验收：** 本地 30s 内出一条带 polyline 的 3–4 站线路。

---

### Layer 1 — 数据质量与 Curated（4–6 周量级）

| 模块 | 内容 |
|---|---|
| `content/curated/` | 编辑精选：安福/愚园等 **20–50 站/区**，带 vibe 标签 |
| POI 融合 | OSM 为主，curated **加权优先**（不替换坐标） |
| 高德补全（可选） | `AMAP_KEY` 补新店名；仍不用上图/馆藏 |
| 缓存 | 片区 POI 快照 JSON，Overpass 失败仍可用 |
| API | `GET /v1/poi/search` · `GET /v1/routes/{id}` |

**验收：** 安福—武康 coffee 线 **店名可读、不重复、步行段 < 20min**。

---

### Layer 2 — 三轴规划器 + 行中会话（6–10 周量级）

| 模块 | 内容 |
|---|---|
| `packages/planner`（或 api 子包） | Mood/Energy/Context 评分、max-min 选站、TSP 近似 |
| 时段 | 夜行 vibe 自动 bias bar/opening_hours |
| 会话 | `POST /v1/routes/{id}/skip` · `POST /v1/routes/{id}/reroll` |
| Web | 行中底部「下一站 / 跳过 / 换线」 |
| 天气（可选） | 开放 API，雨天 boost 室内站 |

**验收：** 行走中跳过一站，**30s 内**重算剩余 polyline。

---

### Layer 3 — 契约 + 叙事润色（8–12 周量级）

| 模块 | 内容 |
|---|---|
| `packages/contracts` | `RouteEnvelope` · `Stop` · `Line` Zod/JSON Schema |
| `narrative/` | LLM **只润色** headline/body/tip；输入必须绑 POI id |
| Guard | 禁止出现未绑定 POI 的店名；失败回退模板 |
| 小程序（可选） | 微信内「出门就走」 |

**验收：** 文案读起来像编辑，但 **每条 fact 可追溯到 POI 记录**。

---

### Layer 4 — 增长与商业化（可选）

| 方向 | 说明 |
|---|---|
| 城市包 | 上海免费 + 其他城市 IAP（参考「溜达」） |
| 品牌联名线 | 咖啡品牌共创「L-C2 联名线」 |
| 本地佣金 | 预约/团购跳转（合规前提下） |
| UGC | 用户「投稿一站」进 curated 审核池 |

## 九、视觉与交互规范

### 9.1 设计 token（已实现）

- 背景 `#0a0f0d` · 主色 `#00e676` · 站码等宽字体
- 组件：LineBadge、MetroDoors（加载）、RouteMap、StationCard

### 9.2 信息层级

1. **LineCode**（L-N1）— 最高优先级
2. **地图 polyline**
3. **站名 + 站码**
4. **tags**（夜行/咖啡…）
5. **正文逛法**

### 9.3 禁止

- 米色书页、印章、典籍引文 UI
- 紫色 SaaS 默认组件风
- 无坐标 POI 展示

---

## 十一、关键指标

| 阶段 | 指标 |
|---|---|
| L0 | Brief → 出线 < 5s（fixture）/ < 15s（live） |
| L1 |  curated 片区 **有效站率 > 80%**（人工抽检） |
| L2 | 行中 skip 后重算 **< 30s** |
| L3 | 叙事 **0 幻觉店名**（自动 + 抽检） |
| 产品 | 完整走线率 **> 60%**（走到终站 / 开始.walk） |

---

## 十二、风险与边界

| 风险 | 应对 |
|---|---|
| Overpass/OSRM 国内不稳定 | curated 缓存 + fixture + 可选高德 |
| OSM 店名缺失/英文 | curated 补全 display_name |
| LLM 幻觉 | L3 前不用 LLM；用后强制 POI 绑定 |
| 合规 | 不爬小红书；UGC 先审后发 |
